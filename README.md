# Mariano Mosquera

Academic website and research knowledge graph.

This repository contains the public web infrastructure for research on institutional ethics, transparency, accountability, compliance, governance, and related fields.

It integrates structured data, semantic vocabularies (SKOS/RDF), academic publications, affiliations, research outputs, and professional activities.
