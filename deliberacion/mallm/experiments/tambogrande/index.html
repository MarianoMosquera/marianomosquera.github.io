Experimento de Tambogrande

Deliberación multiagente con integración ontológica RDF/SKOS y MALLM

Experimento de deliberación artificial aplicado al conflicto minero histórico de Tambogrande (Perú), con ocho agentes que representan actores institucionales y sociales, integración de ontologías éticas y decisión mediante votación de aprobación.

6. Herramientas complementarias y trazabilidad

RecursoContenido
EmbeddingsAcceso al código utilizado para evaluar la diversidad semántica entre agentes, incluida la comparación de las posiciones anteriores y posteriores a la intervención ontológica.
TEST-IAAcceso al código de la herramienta de conexión mediante API de OpenAI utilizada para revisar el manuscrito, con identificación individual y trazabilidad de las modificaciones propuestas por inteligencia artificial.
Aplicación StreamlitInterfaz de TEST-IA para ejecutar la revisión del manuscrito mediante API y consultar la trazabilidad de las modificaciones, conforme al procedimiento declarado en «Arquitectura experimental».
