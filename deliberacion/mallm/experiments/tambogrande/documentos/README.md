# Documentos

Documentación técnica y resultados del experimento de deliberación multiagente aplicado al conflicto histórico de Tambogrande (Perú).

- **Configuración técnica:** implementación de MALLM, integración SKOS y protocolo de deliberación y votación.
- **Diversidad semántica:** análisis comparativo de First Drafts y Second Drafts mediante embeddings.
- **Resultados de Ronda 2:** deliberación, votación y solución aprobada por unanimidad (8/8).
