# Corpus — Recursos para investigación

Repositorio académico de Mariano Mosquera destinado a la recopilación, organización y análisis de corpus documentales para investigación.

Incluye conjuntos de datos, textos y materiales de referencia orientados al análisis académico, conceptual y semántico.

Los recursos están destinados a facilitar la investigación, la reproducibilidad y el desarrollo de metodologías de análisis.
